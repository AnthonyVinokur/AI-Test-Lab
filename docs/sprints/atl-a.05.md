# ATL-A.05 — Trusted Evidence Admission Boundary

ATL-A.05 admits evidence only when frozen integrity, authenticated provenance, trust,
exact binding, intended context, producer/type/version/workflow authorization, freshness,
and replay facts all agree. Every ordinary rejection is stable and the public result exposes
only contract version, decision, and reason code.

## Slice closure

1. Immutable admission contract
2. Strict untrusted translation
3. Trusted prerequisite enforcement
4. Exact evidence/provenance binding
5. Purpose and environment matching
6. Producer, type, version, and workflow authorization
7. Freshness and replay control
8. Deterministic decision
9. Normalized minimal public outcome
10. Integrated and architectural closure

Integrity, cryptography, trust authorization, persistence, deployment authorization,
governance scoring, UI work, and proprietary evidence intelligence remain outside this
boundary.
