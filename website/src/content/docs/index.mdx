AI Test Lab brings structured software-testing practices to AI and LLM applications.

## Current capabilities

- Prompt-based test execution
- Ollama integration
- Contains, not-contains, and equals assertions
- JSON reporting
- HTML reporting
- Response timing metrics
- Token usage metrics
- Automated pytest coverage

## Project direction

AI Test Lab is being developed as an open-source framework for:

- LLM regression testing
- Multi-model comparison
- LLM-as-a-Judge evaluation
- Hallucination detection
- AI security testing
- CI/CD integration
