## Reliable testing for nondeterministic AI systems

AI Test Lab is an open-source Python framework for testing AI and large
language model responses.

It brings familiar software-testing practices into AI engineering by making
model behavior measurable, repeatable, and reportable.

## What problem does it solve?

Traditional automated tests usually expect deterministic behavior.

Given the same input, a normal application function is expected to return the
same output. Large language models behave differently. Their answers can vary
in wording, structure, completeness, accuracy, and safety.

AI Test Lab addresses this problem by separating three concerns:

1. **Prompt execution** — send a test prompt to a selected model.
2. **Response evaluation** — evaluate the result using defined assertions.
3. **Evidence generation** — save responses, decisions, reasons, and metrics
   in structured reports.

This creates a repeatable evaluation pipeline instead of relying on informal
manual prompt testing.
